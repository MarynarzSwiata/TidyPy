# TidyPy

TidyPy is a Python-based desktop utility for organizing files and folders.  
The goal of the project is to provide both a CLI and GUI interface on top of a shared core logic module.

## Features (MVP)

- Scan a directory (optionally recursive)
- Preview planned operations (dry run)
- Rename files using predefined rules
- Create target directories
- Move or copy files
